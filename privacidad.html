Política de privacidad

Última actualización: 17 de noviembre de 2026.

  • Quién la usa: MCP Second Brain es una herramienta personal. Solo la usa su autor, con su propia cuenta de Google.
  • Qué datos usa: los eventos de Google Calendar de esa cuenta (permiso calendar.events), para listarlos, crearlos o moverlos a petición del usuario. No accede a ningún otro dato de Google.
  • Dónde se guardan: en los dispositivos del propio usuario. El token de acceso se guarda en local y no se envía a ningún servidor de terceros.
  • Con quién se comparten: con nadie. No se venden, no se usan para publicidad y no se transfieren a terceros. El uso de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos sus requisitos de uso limitado (Limited Use).
  • Cómo revocar el acceso: en cualquier momento, desde myaccount.google.com/permissions.

Contacto: a través del perfil de GitHub BeatsNahu.
